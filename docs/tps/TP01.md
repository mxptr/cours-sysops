# TP 1 – Prise en main et lancement de l'application

## Objectifs

* Préparer l'environnement de travail.
* Forker et cloner le projet.
* Découvrir l'application Flask.
* Construire une image Docker.
* Lancer l'application dans un conteneur.
* Vérifier son fonctionnement.

## Étapes

### 1. Installer les prérequis

Installer Git et Docker puis vérifier leur installation.

```bash
git --version
docker --version
```

### 2. Forker le dépôt

Ouvrir le dépôt du cours :

https://github.com/oboyo-training/cours-sysops

Cliquer sur **Fork** puis créer le fork dans votre propre compte GitHub.

### 3. Cloner votre fork

Cloner ensuite votre propre dépôt :

```bash
git clone https://github.com/VOTRE_USERNAME/cours-sysops.git

cd cours-sysops
```

Vérifier que vous êtes bien dans le projet :

```bash
ls
```

Vous devez notamment retrouver :

```text
app/
Dockerfile
README.md
docs/
```

### 4. Découvrir l'application Flask

Explorer le répertoire `app/` :

```bash
ls app
```

Lire les deux fichiers :

```text
app/app.py
app/requirements.txt
```

Identifier notamment :

* le framework utilisé ;
* le port d'écoute de l'application ;
* la route principale `/` ;
* la route `/health` ;
* les dépendances Python.

L'application écoute sur le port `5000`.

### 5. Construire l'image Docker

Construire l'image à partir du Dockerfile fourni :

```bash
docker build -t cours-sysops:tp1 .
```

Vérifier que l'image a bien été créée :

```bash
docker images
```

Identifier l'image :

```text
cours-sysops:tp1
```

### 6. Lancer le conteneur

Lancer l'application :

```bash
docker run -d \
  --name cours-sysops-tp1 \
  -p 5000:5000 \
  cours-sysops:tp1
```

### 7. Vérifier le conteneur

Vérifier que le conteneur est en cours d'exécution :

```bash
docker ps
```

Identifier notamment :

* le nom du conteneur ;
* l'image utilisée ;
* le mapping des ports ;
* l'état du conteneur.

### 8. Consulter les logs

Afficher les logs du conteneur :

```bash
docker logs cours-sysops-tp1
```

### 9. Tester l'application

Depuis un navigateur, accéder à :

http://localhost:5000

Tester également avec `curl` :

```bash
curl http://localhost:5000
```

Tester la route de santé :

```bash
curl http://localhost:5000/health
```

La réponse attendue est :

```json
{"status":"ok"}
```

### 10. Observer le fonctionnement

Identifier le port utilisé par l'application et vérifier la correspondance avec le mapping Docker :

```text
Port de l'application : 5000
Port du conteneur      : 5000
Port de la machine    : 5000
```

Le mapping Docker utilisé est :

```text
5000:5000
```

### 11. Arrêter le conteneur

À la fin du TP :

```bash
docker stop cours-sysops-tp1
```

Le conteneur pourra ensuite être supprimé avec :

```bash
docker rm cours-sysops-tp1
```
