# TP 1 – Prise en main et lancement de l'application

## Objectifs

* Préparer l'environnement de travail.
* Cloner le dépôt et découvrir l'application Flask.
* Construire et lancer l'application avec Docker.
* Vérifier son fonctionnement.

## Étapes

### 1. Installer les prérequis

Installer Docker et Git puis vérifier leur installation.

```bash
docker --version
git --version
```

### 2. Cloner le dépôt

Forker au préalable le dépôt du formateur dans votre compte GitHub.

```bash
git clone https://github.com/VOTRE_USERNAME/cours-sysops.git
cd cours-sysops
```

Suivre les instructions du README.

### 3. Construire et lancer l'application

```bash
docker build -t cours-sysops:tp1 .

docker run -d --name cours-sysops-tp1 -p 5000:5000 cours-sysops:tp1
```

### 4. Tester l'application

Accéder à l'application :

http://localhost:5000

Vérifier son état et consulter les logs :

```bash
docker ps

docker logs cours-sysops-tp1

curl http://localhost:5000

curl http://localhost:5000/health
```

### 5. Observer le conteneur

Identifier notamment :

* le nom du conteneur ;
* l'image utilisée ;
* le mapping de ports ;
* l'état du conteneur.

Prochain TP : **TP 2 – Optimiser, taguer et publier une image Docker**
