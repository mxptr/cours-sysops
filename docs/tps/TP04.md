# TP 4 – Déploiement complet avec Kubernetes

## Objectifs

* Gérer la configuration d'une application.
* Utiliser un ConfigMap et un Secret.
* Mettre à jour un déploiement.
* Mettre à l'échelle une application.
* Diagnostiquer un problème simple.

## Étapes

### 1. Créer le cluster Kind

```bash
kind create cluster --name sysops-cluster

kubectl create namespace sysops
```

Réappliquer les manifestes du TP3 :

```bash
kubectl apply -f deployment.yaml
kubectl apply -f service.yaml
```

### 2. Créer un ConfigMap

Créer `configmap.yaml` :

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: cours-sysops-config
  namespace: sysops
data:
  APP_ENV: "production"
```

Appliquer :

```bash
kubectl apply -f configmap.yaml
```

### 3. Créer un Secret

Créer un Secret de démonstration :

```bash
kubectl create secret generic cours-sysops-secret   --from-literal=API_KEY=demo   -n sysops
```

### 4. Injecter la configuration dans le Deployment

Modifier `deployment.yaml` pour ajouter sous le conteneur :

```yaml
          envFrom:
            - configMapRef:
                name: cours-sysops-config
            - secretRef:
                name: cours-sysops-secret
```

### 5. Appliquer la configuration

```bash
kubectl apply -f deployment.yaml

kubectl rollout status deployment/cours-sysops -n sysops
```

### 6. Vérifier les variables

```bash
kubectl exec -n sysops deployment/cours-sysops -- printenv APP_ENV

kubectl exec -n sysops deployment/cours-sysops -- printenv API_KEY
```

Résultats attendus :

```text
production
demo
```

### 7. Vérifier le déploiement

```bash
kubectl get pods -n sysops

kubectl describe deployment cours-sysops -n sysops

kubectl logs deployment/cours-sysops -n sysops
```

### 8. Mettre à l'échelle l'application

Passer à deux réplicas :

```bash
kubectl scale deployment cours-sysops --replicas=2 -n sysops

kubectl get pods -n sysops
```

Revenir à un réplica :

```bash
kubectl scale deployment cours-sysops --replicas=1 -n sysops

kubectl get pods -n sysops
```

### 9. Observer le remplacement automatique d'un Pod

```bash
kubectl get pods -n sysops
```

Identifier un Pod puis :

```bash
kubectl delete pod NOM_DU_POD -n sysops
```

Observer la création automatique d'un nouveau Pod :

```bash
kubectl get pods -n sysops -w
```

### 10. Tester l'application

```bash
kubectl port-forward -n sysops svc/cours-sysops 8080:80
```

Puis :

```bash
curl http://localhost:8080
```

### 11. Nettoyer

```bash
kind delete cluster --name sysops-cluster
```
