# TP 3 – Premier déploiement Kubernetes

## Objectifs

* Découvrir les objets Kubernetes.
* Utiliser un cluster Kubernetes local avec Kind.
* Déployer une application à partir d'une image Docker.
* Exposer l'application avec un Service.
* Vérifier son fonctionnement.

## Étapes

### 1. Installer Kind et kubectl

Installer Kind et kubectl puis vérifier leur installation :

```bash
kind version

kubectl version --client
```

### 2. Créer le cluster Kind

```bash
kind create cluster --name sysops-cluster
```

Vérifier l'accès au cluster :

```bash
kubectl cluster-info --context kind-sysops-cluster

kubectl get nodes
```

### 3. Créer le namespace

```bash
kubectl create namespace sysops
```

### 4. Créer le Deployment

Créer un fichier `deployment.yaml` avec l'image publiée sur GHCR.

Remplacer `OWNER` par votre compte GitHub ou organisation.

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cours-sysops
  namespace: sysops
spec:
  replicas: 1
  selector:
    matchLabels:
      app: cours-sysops
  template:
    metadata:
      labels:
        app: cours-sysops
    spec:
      containers:
        - name: cours-sysops
          image: ghcr.io/OWNER/cours-sysops:tp2
          ports:
            - containerPort: 5000
```

### 5. Déployer l'application

```bash
kubectl apply -f deployment.yaml

kubectl get deployments -n sysops

kubectl get pods -n sysops

kubectl rollout status deployment/cours-sysops -n sysops
```

### 6. Créer le Service

Créer `service.yaml` :

```yaml
apiVersion: v1
kind: Service
metadata:
  name: cours-sysops
  namespace: sysops
spec:
  selector:
    app: cours-sysops
  ports:
    - port: 80
      targetPort: 5000
  type: ClusterIP
```

Appliquer le Service :

```bash
kubectl apply -f service.yaml

kubectl get svc -n sysops
```

### 7. Tester l'application

Dans un terminal :

```bash
kubectl port-forward -n sysops svc/cours-sysops 8080:80
```

Dans un autre terminal :

```bash
curl http://localhost:8080
```

Accéder également à :

http://localhost:8080

### 8. Nettoyer

À la fin du TP :

```bash
kind delete cluster --name sysops-cluster
```
