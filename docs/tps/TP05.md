# TP 5 – Premier workflow GitHub Actions

## Objectifs

* Découvrir les workflows GitHub Actions.
* Automatiser la construction d'une image Docker.
* Publier automatiquement l'image sur GHCR.
* Vérifier l'exécution du workflow.

## Étapes

### 1. Préparer le dépôt

Créer le répertoire :

```bash
mkdir -p .github/workflows
```

### 2. Créer le workflow

Créer le fichier :

```text
.github/workflows/ci.yml
```

Le workflow doit :

* se déclencher lors d'un push sur la branche `main` ;
* récupérer le code source ;
* se connecter à GHCR ;
* construire l'image Docker ;
* publier l'image sur GHCR.

Utiliser le tag :

```text
ghcr.io/OWNER/cours-sysops:tp5
```

### 3. Configurer les permissions

Le workflow doit disposer des permissions nécessaires pour publier une image sur GHCR, notamment :

```yaml
permissions:
  contents: read
  packages: write
```

### 4. Déclencher le workflow

```bash
git add .

git commit -m "Add GitHub Actions workflow"

git push origin main
```

### 5. Vérifier l'exécution

Dans GitHub :

1. ouvrir l'onglet **Actions** ;
2. vérifier que le workflow s'est exécuté correctement ;
3. ouvrir **Packages** ;
4. vérifier la présence de l'image `cours-sysops` avec le tag `tp5`.
