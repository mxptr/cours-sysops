# TP 2 – Optimiser, taguer et publier une image Docker

## Objectifs

* Optimiser le Dockerfile avec une image Python plus légère.
* Réduire la taille de l'image Docker.
* Exécuter l'application avec un utilisateur non-root.
* Construire une nouvelle version de l'image.
* Taguer l'image pour GitHub Container Registry.
* Publier l'image sur GitHub Container Registry (GHCR).
* Vérifier que l'image publiée peut être récupérée.

---

## Étapes

### 1. Optimiser le Dockerfile

À partir du Dockerfile utilisé au TP1, améliorez l'image Docker.

Les modifications demandées sont :

* remplacer `python:3.11` par `python:3.11-slim` ;
* installer les dépendances avec `--no-cache-dir` ;
* créer un utilisateur `appuser` ;
* donner à cet utilisateur les droits nécessaires sur `/app` ;
* exécuter l'application avec cet utilisateur.

Le Dockerfile attendu doit suivre cette logique :

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY app/requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY app/ .

RUN useradd --create-home appuser \
    && chown -R appuser:appuser /app

USER appuser

EXPOSE 5000

CMD ["python", "app.py"]
```

### 2. Construire l'image optimisée

Construire une nouvelle image :

```bash
docker build -t cours-sysops:tp2 .
```

Vérifier les images disponibles :

```bash
docker image ls cours-sysops
```

Vous devez retrouver notamment :

```text
cours-sysops:tp1
cours-sysops:tp2
```

### 3. Comparer les images

Comparez les deux images :

```bash
docker image ls cours-sysops
```

Observez notamment leur taille.

### 4. Vérifier le fonctionnement

Vérifier si le conteneur du TP1 existe encore :

```bash
docker ps -a
```

S'il existe encore, arrêter et supprimer le conteneur :

```bash
docker stop cours-sysops-tp1
docker rm cours-sysops-tp1
```

Lancer l'image optimisée :

```bash
docker run -d \
  --name cours-sysops-tp2 \
  -p 5000:5000 \
  cours-sysops:tp2
```

Vérifier le conteneur :

```bash
docker ps
```

Tester l'application :

```bash
curl http://localhost:5000
```

Tester également la route de santé :

```bash
curl http://localhost:5000/health
```

### 5. Vérifier l'utilisateur utilisé

Vérifier l'utilisateur du conteneur :

```bash
docker exec cours-sysops-tp2 whoami
```

Le résultat attendu est :

```text
appuser
```

Vous pouvez également vérifier la configuration de l'image :

```bash
docker inspect cours-sysops-tp2 --format='{{.Config.User}}'
```

Le résultat attendu est :

```text
appuser
```

### 6. Préparer l'image pour GHCR

Remplacez `VOTRE_USERNAME` par votre nom d'utilisateur GitHub.

Taguer l'image :

```bash
docker tag cours-sysops:tp2 \
  ghcr.io/VOTRE_USERNAME/cours-sysops:tp2
```

Vérifier :

```bash
docker image ls
```

Vous devez retrouver une image similaire à :

```text
ghcr.io/VOTRE_USERNAME/cours-sysops   tp2
```

---

### 7. Se connecter à GitHub Container Registry

Pour publier une image depuis votre machine, vous devez utiliser un **Personal Access Token (classic)** disposant au minimum de la permission :

```text
write:packages
```

Créer le token depuis les paramètres GitHub.

⚠️ Ne partagez jamais votre token et ne le committez jamais dans Git.

Définir temporairement le token :

```bash
export CR_PAT="VOTRE_TOKEN"
```

Se connecter à GHCR :

```bash
echo "$CR_PAT" | docker login ghcr.io \
  -u VOTRE_USERNAME \
  --password-stdin
```

Vous devez obtenir :

```text
Login Succeeded
```

Supprimer ensuite la variable :

```bash
unset CR_PAT
```

---

### 8. Publier l'image

Publier l'image :

```bash
docker push ghcr.io/VOTRE_USERNAME/cours-sysops:tp2
```

Observer les différentes couches envoyées vers le registry.

---

### 9. Vérifier le package GitHub

Dans GitHub, ouvrir la section **Packages** de votre compte.

Vérifier la présence du package :

```text
cours-sysops
```

et du tag :

```text
tp2
```

> Attention : un package publié pour la première fois sur GHCR est privé par défaut.

Pour la suite du TP, configurez le package `cours-sysops` en **Public** afin que Kubernetes puisse récupérer l'image sans authentification supplémentaire.

---

### 10. Tester le téléchargement de l'image

Supprimer l'image locale :

```bash
docker rmi ghcr.io/VOTRE_USERNAME/cours-sysops:tp2
```

Puis télécharger à nouveau l'image depuis GHCR :

```bash
docker pull ghcr.io/VOTRE_USERNAME/cours-sysops:tp2
```

Vérifier :

```bash
docker image ls
```

L'image doit maintenant être disponible localement.
