# TP 2 – Optimiser, taguer et publier une image Docker

## Objectifs

* Optimiser le Dockerfile avec une image Python plus légère.
* Exécuter l'application avec un utilisateur non-root.
* Construire et taguer une nouvelle image.
* Publier l'image sur GitHub Container Registry (GHCR).

## Étapes

### 1. Optimiser le Dockerfile

À partir du Dockerfile du TP1 :

* remplacer `python:3.11` par `python:3.11-slim` ;
* installer les dépendances sans conserver le cache pip ;
* créer un utilisateur non-root ;
* donner à cet utilisateur les droits nécessaires sur `/app` ;
* exécuter l'application avec cet utilisateur.

Le Dockerfile attendu doit suivre cette logique :

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY app/requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY app/ .

RUN useradd --create-home appuser     && chown -R appuser:appuser /app

USER appuser

EXPOSE 5000

CMD ["python", "app.py"]
```

### 2. Construire la nouvelle image

```bash
docker build -t cours-sysops:tp2 .
```

### 3. Comparer les tailles

```bash
docker image ls cours-sysops

docker image inspect cours-sysops:tp1 --format='{{.Size}}'

docker image inspect cours-sysops:tp2 --format='{{.Size}}'
```

### 4. Vérifier le fonctionnement

Arrêter et supprimer le conteneur du TP1 si nécessaire :

```bash
docker stop cours-sysops-tp1
docker rm cours-sysops-tp1
```

Lancer l'image optimisée :

```bash
docker run -d --name cours-sysops-tp2 -p 5000:5000 cours-sysops:tp2
```

Tester :

```bash
curl http://localhost:5000
```

Vérifier l'utilisateur :

```bash
docker exec cours-sysops-tp2 whoami
```

Le résultat attendu est :

```text
appuser
```

### 5. Taguer l'image

Remplacer `OWNER` par votre compte GitHub ou organisation.

```bash
docker tag cours-sysops:tp2 ghcr.io/OWNER/cours-sysops:tp2
```

### 6. Se connecter à GHCR

Utiliser un token GitHub disposant des droits nécessaires pour publier des packages.

```bash
echo VOTRE_TOKEN | docker login ghcr.io -u OWNER --password-stdin
```

### 7. Publier l'image

```bash
docker push ghcr.io/OWNER/cours-sysops:tp2
```

### 8. Vérifier la publication

Vérifier dans GitHub Packages la présence du package et du tag `tp2`.

Tester également :

```bash
docker pull ghcr.io/OWNER/cours-sysops:tp2
```
